3 · OrchestrationThe nurse worklist

Each member with an open CURRENT need gets one contact: a call due by SLA (P1 today, P2 next day, P3 in 3 days) or a digital nudge for P4. No new contact goes out within 14 days of a reached call. The list is ordered safety or RED → tier → campaign priority → due date. Nurses are matched by language, round-robin, within daily capacity; anything over capacity is queued for the next day. 4 · Write-backHow a nurse's action becomes a follow-up

Each portal button calls POST /actions/{id}/outcome. In one transaction, 05_followup.sql records the outcome, closes the action, moves the need, creates the follow-up action (linked by parent_action_id), and promotes the next need into CURRENT with its own action.

6 · SQLThe formulas that carry the rules

-- G0 cleaning (generated for every column): impossible values and 999 placeholders → NULL
CASE WHEN CAST(x AS DECIMAL) BETWEEN 60 AND 260 THEN CAST(x AS DECIMAL) END          -- systolic BP
CASE WHEN x REGEXP '^[0-9]{1,2}/[0-9]{1,2}/[0-9]{4}$' THEN STR_TO_DATE(x, '%m/%d/%Y') END

-- Rulebook §2 and §4
r_total  = clinical_score + comorbid_complication_score + kidney_score + utilization_score + age_sex_score
tier     = rule_tier WHERE r_total BETWEEN r_min AND r_max
alert    = RED   (safety flag · DKA · hypo · BP ≥ 180/110 · eGFR < 15)
         | AMBER (post-discharge · HbA1c ≥ 9 · BP ≥ 160/100 · PDC < 50%) | YELLOW (any trigger) | GREEN
priority = first rule_priority row for (alert, needs_trigger)   -- AMBER + post-discharge = P1

-- Raw member → trigger (one block per trigger, generated from the rule database)
WHERE (t.use_variant = 'extract'  AND m.trig1_hba1c_above_target = 1)
   OR (t.use_variant = 'rulebook' AND m.cohort_t2d_l12m = 1 AND m.last_hba1c_value >= 8)

-- Slots, holdout, worklist
slot       = CASE WHEN ROW_NUMBER() OVER (PARTITION BY member_id ORDER BY class_order, trigger_order) <= 3 THEN 'CURRENT' … END
holdout    = CRC32(CONCAT(campaign_id, ':', member_id)) % 100 < 10
rank_no    = ROW_NUMBER() OVER (ORDER BY urgent DESC, tier DESC, campaign_priority, due_date)
nurse      = nurse_language WHERE language = member.language AND lang_idx = MOD(lang_rn - 1, n_nurses) + 1
nurse_rank = ROW_NUMBER() OVER (PARTITION BY nurse_id ORDER BY rank_no)  → 'today' while ≤ daily_capacity

Files: 01_schema · 02_rules · 02b_setup · 03_load · 04_nightly (8 steps) · 05_followup (8 statements) · 06_views (7 views). The rule-dependent parts are generated from rules/*.csv, so the SQL can't drift from the signed-off rules.
